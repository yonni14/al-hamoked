# על המוקד | Al-Hamoked

פורום לדיבייט ציבורי בירושלים — אירועים פתוחים עם דוברים מקצועי הפוליטיקה.

**אתר חי:** https://alhamoked.co.il

אתר סטטי תלת־לשוני (עברית / English / العربية) בלי build — HTML, CSS ו־JavaScript טהורים, מתארח ב־GitHub Pages.

- `index.html` — דף הבית והאירועים
- `ticket.html` / `admin.html` — רשימת המתנה, מכירת כרטיסים משנית וניהול (מבוססי Supabase; הסכמה ב־`supabase/waitlist.sql`)
- `js/`, `css/` — לוגיקה ועיצוב
- `data/` — אירועים בקבצי JSON לפי שפה
- `assets/` — תמונות דוברים, לוגואים ורקעים

---

A trilingual (Hebrew / English / Arabic) static site for Al-Hamoked, a public debate forum in Jerusalem. Plain HTML/CSS/JS on GitHub Pages, with a Supabase-backed waiting list and ticket-resale flow.
